# gelo

## Claude Code plugin: `gelo-skills`

This repo is also a Claude Code plugin marketplace. Install the plugin with:

```
/plugin install gelo-skills --marketplace G3LO1/gelo
```

On older Claude Code versions, add the marketplace first:

```
/plugin marketplace add G3LO1/gelo
/plugin install gelo-skills@gelo
```

See [`plugins/gelo-skills/README.md`](plugins/gelo-skills/README.md) for the skill list and how to add new skills.
