# gelo

Claude Code plugin for making Roblox games in Roblox Studio.

## Install

```
/plugin install gelo-skills --marketplace G3LO1/gelo
```

On older Claude Code versions, add the marketplace first:

```
/plugin marketplace add G3LO1/gelo
/plugin install gelo-skills@gelo
```

The skills work best with the Roblox Studio MCP tools connected, so Claude can build and playtest directly in your place.

## Skills

| Skill | What it does |
| --- | --- |
| [`roblox-map-builder`](plugins/gelo-skills/skills/roblox-map-builder/SKILL.md) | Builds aesthetic, correct and performant maps (terrain, buildings, lighting, props, procedural generation, validation) in any style. |

See [`plugins/gelo-skills/README.md`](plugins/gelo-skills/README.md) for how to add new skills.
