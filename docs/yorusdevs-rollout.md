## 1. Layered VFX

Sources: [masks and 4x4 flipbook, 2:32](https://www.youtube.com/watch?v=7VQpF5ERE0M&t=152s),
[edge check, 4:07](https://www.youtube.com/watch?v=7VQpF5ERE0M&t=247s),
[sheet preview with the frame lit up, 8:22](https://www.youtube.com/watch?v=u5ig8f1Nzyg&t=502s).

Landed:
- `assets/Vfx.luau`: emitters take optional `layer`, `flipbook` (`layout` Grid2x2/4x4/8x8, `mode`,
  `framerate`, `startRandom`), `rotation` and `minQuality`; presets take `variants`
  (variant -> layer -> colors); options take `variant` and `layerColors`. Color precedence:
  `layerColors[layer]` > `variants[variant][layer]` > `color` > the preset's own. `Vfx.variants(name)`.
  Reduced flashing turns `Random` flipbook frame jumps into `Loop`. Old presets are unchanged.
- `Slash` preset: three white layers (Glow, Body, Core) on one sheet, variants Frost and Ember;
  the Glow layer drops below quality 0.5 (fill-rate).
- `assets/textures/slash_4x4.png`: original 512 px sheet, 16 frames of 128 px, generated by
  `scripts/make_textures.py` (grows in, holds, tears apart along the flow; tapered ends; >= 9 px
  clear of every cell edge).
- `scripts/flipbook.py`: `pack` (frames dir / files / animated GIF -> sheet; `--fit` same scale for
  every frame inside the margin; `--white` white mask), `check` (square, power of two, <= 1024 px,
  grid, 4 px margins, empty frames, haze, white), `preview` (HTML: frame playing per tint next to
  the sheet with that frame lit up; `?frame=N`).
- `scripts/vfx_showcase.luau`: one pad per color variant (`Slash_Ember`, `Slash_Frost`).
- Docs: `references/vfx.md` section 8, `references/blender.md` section 8, `SKILL.md` wiring.

Verified (this environment, Lune 0.10.4, Python 3.13 + Pillow, bpy 5.3.0):
- `bash tests/roblox-animation-vfx/run.sh`: 41 passed, 0 failed (vfx_test.luau 37 passed,
  blender_test.py 19 passed). New: 16 Luau checks for layers/variants/quality/reduced flashing/old
  presets, 19 flipbook.py checks on generated good and broken sheets (`make_flipbooks.py`).
- The new Luau checks fail when variant colors, `minQuality` or the Random -> Loop rule are removed.
- `python3 llm/build.py --check` OK; `bash tests/roblox-launch-kit/run.sh` 24 passed.
- Preview HTML opened in Chromium at 1100 px and 390 px wide: frame highlight follows the player,
  no horizontal scroll, no console errors.

2. `lune run scripts/vfx_showcase.luau assets/Vfx.luau VfxShowcase.rbxmx`, insert the model, look at

## 2. UI components

Sources: [layers, 2:39](https://www.youtube.com/watch?v=e3U3lJDftOQ&t=159s),
[stretching frames, 3:14](https://www.youtube.com/watch?v=e3U3lJDftOQ&t=194s),
[one table of motion numbers, 3:29](https://www.youtube.com/watch?v=e3U3lJDftOQ&t=209s),
[dark strip and text size after import, 5:59](https://www.youtube.com/watch?v=e3U3lJDftOQ&t=359s).

Landed:
- `assets/examples/components.json`: state gallery with `ItemCard` and `Button`, each a transparent
  ImageButton holding white layers (Glow behind, Base/Glass, Edge, ItemGlow, Icon, labels, gold line),
  9-sliced where they stretch, in Default / Focused / Pressed / Disabled. `assets/examples/images/`
  holds the original layer PNGs (`scripts/make_ui_images.py`; the glow is a ring with an empty middle).
- ui-spec `motion`: one table (hoverScale 1.04, pressScale 0.98, hoverTime 0.12, pressTime 0.08,
  openTime 0.3, stagger 0.05, glow transparencies, disabledTransparency, breathe), range-checked,
  turned into `$Motion*` tokens. Style rules take `transition` (StyleRule:SetDefaultPropertyTransition).
- `assets/UiStates.luau`: client runtime that tags components `StateFocused` / `StatePressed` /
  `StateDisabled` from mouse, touch (never hovers) and gamepad (selection + A); `Disabled` attribute
  turns off Interactable/Selectable; glow breathes while focused; `open()` pops components in one after
  another; reduced motion; the glow replaces the default gamepad selection box.
- `spec_to_luau.py`: rejects unknown state selectors (`:Pressed` -> use `:Press`) and spaces as
  combinators (`>>`), checks `motion`, `transition`, 9-slice (no SliceCenter, inverted rect, past the
  PNG size with `--images`).
- `preview_ui.py`: local images tinted by ImageColor3, 9-slice, ImageTransparency, UIScale, `>`/`>>`
  selector chains, motion tokens, data-name/class/tags on every element.
- Fix: `TextButton:Pressed` is not a Roblox state (Enum.GuiState: Idle, Hover, Press, NonInteractable).
  The undead-eats spec and its BuildUi.luau now use `:Press`; docs corrected in ui-spec.md, studio.md,
  figma.md, photoshop.md.

Verified (Lune 0.10.4, Chromium via Playwright):
- `bash tests/roblox-ui-designer/run.sh`: 31 passed, 0 failed. New: components build + validation
  against the API database (100 instances, style rules, transitions), no warnings with `--images`;
  layer images reproducible; `states_test.luau` 27 checks; 8 broken-spec cases; `preview_check.js`
  at 1920x1080 and 844x390 (8 components, >= 44 px, below the top bar, no overlaps, focused grows,
  pressed shrinks, disabled dimmed, 9-slice drawn).
- States tests fail when the touch hover reset, the disabled press reset or the gamepad selection
  guard is removed.
- Unchanged: undead-eats 51 passed, luau-codegen 49 passed, launch-kit 24, security audit 11,
  animation-vfx 40 (+ blender 19 with bpy), `claude plugin validate` OK, LLM pack up to date.

## 3. Batch model preparation

Sources: [references per part, no effects, 1:04](https://www.youtube.com/watch?v=FA_d0M3-Onw&t=64s),
[face limits and dry run, 2:40](https://www.youtube.com/watch?v=FA_d0M3-Onw&t=160s),
[what comes out wrong, 3:43](https://www.youtube.com/watch?v=FA_d0M3-Onw&t=223s),
[one Blender script for every model, 4:13](https://www.youtube.com/watch?v=FA_d0M3-Onw&t=253s).

Landed:
- `scripts/model_batch.py` (runs in Blender: `blender -b --python`, `python` with bpy, or a Blender
  MCP code tool): per model import (fbx/obj/glb/gltf/blend), drop extra objects (`keep`), bake
  transforms and join, turn so `up` -> +Z and `front` -> -Y, scale to `studs`, `fillHoles`, decimate to
  `maxTriangles`, named `points` (bounding-box fractions), `pivot` (bottom/center/top/point),
  blender_check.py (model mode; errors fail the model), FBX with blender_check's export settings, icon
  from one fixed orthographic camera (Cycles CPU, transparent).
- `--dry-run` does all of it in memory and prints the plan; writes nothing.
- `model_batch_state.json`: key = source bytes + settings + VERSION; unchanged models are skipped,
  changed ones redone, failed ones retried; saved after every model (resume). `--only`, `--force`.
- Outputs `models.json` and `ModelSpecs.luau` (Size, PivotOffset, Attachments in Roblox axes relative
  to the MeshPart center; `apply(part)` sets the pivot, creates/moves Attachments, warns on scale).
- `assets/examples/models.json`: Katana (lying, wrong facing, extra scabbard, grip pivot), Spear (too
  dense, decimated), Pedestal (open top, FBX source, bottom pivot).
- Docs: `references/blender.md` section 10 (sources, manifest, run, resume, Studio side, axes, what
  stays manual), SKILL.md, map builder (kits), README; CI blender job runs the batch test + Lune.

Verified (bpy 5.3.0, Lune 0.10.4):
- `model_batch_test.py`: 32 passed. Generated sources wrong the way image-to-3D output is; dry run
  writes nothing; exported FBX re-imported and measured (Katana 4 studs upright, edge toward -Y,
  grip pivot; Spear 6.5 studs, 19194 -> 1454 triangles; Pedestal 1.5 studs, bottom pivot,
  watertight); icons 256 px transparent and upright; second run skips all; changed setting / changed
  source redo only that model; missing source fails only that model and is retried; 6 manifest
  errors; command line from a fresh interpreter (exit 0 / 2).
- `model_specs_test.luau`: 8 passed on real MeshParts (pivot, reused/created Attachments, scale warning).
- Mutations caught: front mapped to +Y, never skipping, dry run writing.
- Found and fixed while testing: with bpy from PyPI, `bmesh`/`mathutils` import only after `bpy`.
- All suites: animation-vfx 43, ui-designer 31, launch-kit 24, security 11, undead-eats 51,
  luau-codegen 49; plugin validate OK; LLM pack up to date.
